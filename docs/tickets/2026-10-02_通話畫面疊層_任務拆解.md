# 視訊通話畫面疊層修正 任務拆解

## 現況與前提
- 技術棧：Flutter 3.44.4（stable）、agora_rtc_engine 6.5.4。
- 既有相關機制：通話畫面 [video_call_screen.dart](../../lib/screens/community/video_call_screen.dart) 用一個 `Stack(fit: expand)` 疊出：全螢幕對方影像 → 上方計時列與右上 `PopupMenuButton`（加好友／封鎖）→ 名字 → 右上自己的小窗 → 底部控制列（靜音／鏡頭／結束）。影像由 [agora_video_rtc.dart](../../lib/screens/community/video_call/agora_video_rtc.dart) 的 `AgoraVideoView` 提供，沒有設 `useFlutterTexture`，兩個平台都走原生 platform view（Android `AgoraTextureView`、iOS `AgoraSurfaceView`）。
- 原因（已確認）：只有 iOS 有問題。iOS 的 `AgoraSurfaceView` 蓋掉疊在上面的 Flutter 元件，底部控制列看不到、右上選單被裁在影像範圍內。診斷 build（`diag/call-overlay`，1.0.0+18，對方影像換成純色）在 iOS 上控制列與選單都正常；Android 舊版本來就正常。
- 這次會動到的既有部位：`agora_video_rtc.dart` 的 `localView()`／`remoteView()`。
- 已定案的技術前提：手機優先，修正不得改變通話流程與狀態機（[video_call_controller.dart](../../lib/screens/community/video_call/video_call_controller.dart) 不動）。1.0.0+18 已被診斷 build 用掉，正式版從 +19 起。

## 任務卡

### T-01 iOS 通話中看得到並能操作控制列與右上選單

**使用者價值**：iOS 使用者接通後能自己掛斷、靜音、關鏡頭，也能在通話中加好友或封鎖對方；現在只能等對方掛斷，遇到騷擾時無法即時封鎖。

**範圍**
- 包含：iOS 影像改用 Flutter 紋理渲染，讓控制列、選單、自己的小窗正常疊在對方影像上。
- 不包含：Android 渲染方式（維持現狀）；選單項目與封鎖／加好友流程本身；升級 Agora 套件（見文末備註）。

**驗收條件**
- [ ] iOS 實機：對方影像出現後，底部「靜音／鏡頭／結束」三顆按鈕與文字都看得到，點了有反應（靜音紅底、鏡頭關閉顯示「已關閉鏡頭」、結束走掛斷流程）。
- [ ] iOS 實機：點右上「⋯」選單完整展開；隨機配對看得到「加好友」「封鎖對方」，好友通話只有「封鎖對方」；封鎖確認後結束通話並提示「已封鎖對方，通話已結束」。
- [ ] iOS 實機：右上自己的小窗顯示自己的畫面，圓角正常；對方與自己的影像不黑屏、不拉伸，通話 1 分鐘以上不卡頓、不閃爍。
- [ ] Android 實機：控制列、選單、影像表現與修改前相同。

**實作設計**
- 前端：`AgoraVideoRtc.localView()`／`remoteView()` 的 `VideoViewController`（與 `.remote`）帶 `useFlutterTexture`，只在 `defaultTargetPlatform == TargetPlatform.iOS` 時為 true，並在程式註解寫明這是繞過 iOS platform view 疊層問題、升級套件修好後可移除。改走套件內建的 `AgoraRtcRenderTexture`（iOS 原生端有 `TextureRenderer`），影像成為一般 Flutter 圖層，疊層順序照 `Stack` 走。
- 前端：兩個 view 目前每次 rebuild（計時器每秒）都 new 一個 controller；換成紋理渲染後確認不會每秒重建紋理（`isSame` 會比對）。若有閃爍，把 controller 快取在 `AgoraVideoRtc`，在 `release()` 時清掉。
- 診斷分支 `diag/call-overlay` 不合併，修正從 master 另開分支；TestFlight 上的 +18 診斷 build 設為過期。

**依賴**：無

**風險 / 待決**：紋理渲染多一次拷貝，低階機可能較耗電發熱，實機觀察即可；controller 快取與否由實作者依是否閃爍決定。

**進度**：實作完成，待 iOS／Android 實機驗收。controller 不快取：對照套件原始碼，每秒 rebuild 產生的新 controller 經 `isSame` 判定相同，沿用既有紋理不重建；實機若看到閃爍再改成快取。實機驗收時一併確認 iOS 自己的小窗左右鏡像正確（紋理路徑改由 Flutter 端處理鏡像）。

## 備註：其他可行做法（暫不採用）

紋理渲染是繞過問題，不是根治。Flutter 元件疊在 iOS 原生影像上本來就是 Agora 官方範例的用法，這次失效很可能是 Flutter 3.44 或 agora_rtc_engine 6.5.4 的版本問題。

- **升級 agora_rtc_engine（目前最新 6.6.4）或查 Flutter 版本**：若有效即為根治，兩平台回到同一寫法。每試一次都要出 TestFlight build 找人測，且升級可能影響其他通話行為，所以留待之後另外試。若升級後 platform view 疊層恢復正常，可移除 iOS 的紋理渲染分支。
- **維持 platform view、改版面讓按鈕不疊在影像上**：對方影像縮到控制列上方、選單移出影像範圍。不需改渲染方式，但對方畫面不再全螢幕、設計要重排，而且自己的小窗同樣是 platform view，疊在對方影像上的部分可能仍有問題。
