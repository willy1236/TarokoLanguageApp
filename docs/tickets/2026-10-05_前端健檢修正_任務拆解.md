## 現況與前提

- 技術棧：Flutter（以 Android／iOS 為主），後端是 Truku_backend（Express＋PostgreSQL，Cloud Run），推播用 FCM，即時連線是 `wss://…/ws`，視訊用 Agora。目前版本 `1.0.0+20`。
- 既有相關機制：
  - **推播與即時連線**：通話事件有三個來源：前景推播、點通知、即時連線。三者都走 [fcm_service.dart](../../lib/services/fcm_service.dart) 的 `_handleCallEvent`，用 `type:id` 去重，最多記 50 筆。即時連線的事件如果沒有畫面接手，就不記下，留給隨後的推播。`friend_call_incoming` 不一樣：`_dispatchCallEvent` 一律立刻回傳 true，非同步的 `_fetchIncomingCall` 還沒查到結果，這一則就已經記為處理過。
  - **推播導頁**：[content_push_navigation.dart](../../lib/screens/content_push_navigation.dart) 與 [friend_push_navigation.dart](../../lib/screens/friends/friend_push_navigation.dart) 的規則是：目標頁已在最上層（route name 相同）時，呼叫該頁的 `refreshRoute` 就地重載；否則疊一份新的，不 pop，以免拆掉通話。活動、論壇、處置詳情、私訊四種詳情頁都用「靜態 `_live` Map＋`refreshRoute`」。`InboxScreen.route` 沒有 `RouteSettings(name:)`，`openInboxPush` 每次都直接 push。
  - **論壇回覆推播**：後端 data 是 `{type, post_id, comment_id, inbox_id?}`（`forum-comments.ts:204`）。`_parseForumPayload` 只取 `post_id`。`ForumDetailScreen.route` 已經支援 `focusCommentId`，收件匣點進去時有用，最多會多載 5 頁去找那則留言。
  - **陌生人私訊**：非好友可以先傳 3 則（好友社交串接指南 §87）。`openFriendPush` 先用 `FriendService.findFriend` 查，查不到就導去好友邀請頁。
  - **條款導頁**：`ApiClient._forceConsent` 用 `_showingConsent` 防止重複推頁。[chat_socket_service.dart:226](../../lib/services/chat_socket_service.dart#L226) 收到 close code 4003 時，直接 `pushNamed('/terms-consent')`，沒有這個防護。同意完成後，`TermsConsentScreen._finish` 會清空整個 stack 回 `/home`，新的 `FriendsListScreen.initState` 會重新 `connect()`。
  - **啟動續期**：`SessionService.restore` 在 JWT 過期時呼叫 `AuthService.refreshSession()`，換不到就 `signOut(unregisterDevice: false)`，連 Firebase 一起登出。`refreshSession` 只回 bool，分不出「網路不通」和「被後端拒絕」。JWT 效期 30 天（`backend/auth.ts` 的 `JWT_EXPIRES_DAYS`）。
  - **分頁**：[page_info.dart](../../lib/models/page_info.dart) 提供 `PageInfo`（只看 `nextCursor`）和 `appendUnique`。活動列表共用 [paged_event_list.dart](../../lib/screens/events/widgets/paged_event_list.dart) 的 `PagedEventList(loadPage, itemBuilder, emptyState, seniorMode, reloadSignal)`，它有世代守衛、失敗重試、`_checkNearEnd`。下列列表各自寫分頁，loadMore 沒有世代守衛：小米幣明細、論壇按讚貼文、論壇按讚留言、文章按讚收藏、影音按讚收藏。[event_liked_bookmarked_list.dart](../../lib/screens/events/event_liked_bookmarked_list.dart) 有世代守衛，但 `_load` 不會重設 `_loadingMore`。
  - **活動列表**：[events_screen.dart](../../lib/screens/events/events_screen.dart) 的 `_load` 只抓第一頁，把 `pageInfo` 丟掉，分類篩選只在已載入的資料上做。篩選列是寫死的 `['全部', '族語', '走讀', '工藝', '線上', '音樂', '其他']`，用字串完全相等比對 `category`。後端 origin/main（`b2d61ba`，2026-10-03）的 `events-list.ts` 規格如下：
