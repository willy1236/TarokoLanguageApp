## 任務卡

### T-01 單字測驗有未完成的舊測驗時，能放棄它改測想要的等級

**使用者價值**：想換等級的人不必先把舊測驗做完或等 15 天自動清除，按一下就能開始想測的等級。

**範圍**
- 包含：單字 abandon 端點的 inspector 測試、service、`QuizFlowController` 支援三種選擇與放棄後重開、單字畫面的對話框。
- 不包含：聽力畫面（T-02）；分級測驗不會回 `conflicting_level`，不動。

**驗收條件**
- [x] 有未完成「初級」時點「中級」，對話框有三個選項：繼續「初級」測驗、放棄舊測驗並開始「中級」、返回；不再出現「目前尚不支援直接放棄舊測驗」
- [x] 選放棄後跳出二次確認（已作答的題目不會保留）；按取消回到三選項對話框
- [x] 確認放棄後進入「中級」新測驗，標題顯示中級，題目沒有預先勾選
- [x] 選繼續的行為與現在相同；選返回回到上一頁
- [x] abandon 回 404 時照樣開出新測驗，使用者看不到錯誤
- [x] abandon 回 409 時顯示後端 `error.message`，接著開出測驗
- [x] abandon 網路失敗時進錯誤畫面，按重試會重新 start 並再次出現衝突對話框
- [ ] 回到首頁後，學習頁不再顯示「初級」有未完成的測驗（若首頁有此提示）

**實作設計**
- 前端：
  - 先在 `api_inspector_test.dart` 加 `POST /api/quiz/abandon` raw 測試：start 一個等級、再用另一個等級 start 取得 `conflicting_level` 與舊 `session_id`、abandon、再 start 確認拿到新等級；同時打一次重複 abandon 確認 404 的 `code`。需要人在裝置上點 Google 帳號，跟 T-02 的聽力測試一起錄。
  - `ApiConfig` 加 `quizAbandon`；`LearnService.abandonQuiz(sessionId)` 回傳 `void`，404 在 service 內吞掉視為成功，409 照樣丟 `ApiException` 給上層。
  - `QuizFlowController`：
    - `confirmConflict` 的回傳型別由 `bool` 改成列舉（例如 `QuizConflictChoice { resume, abandon, back }`），畫面不再自己組 bool 語意。
    - 新增可選的注入函式 `abandon: Future<void> Function(String sessionId)?`；沒注入時畫面不應給出放棄選項。
    - `load()` 收到 `abandon`：呼叫 `abandon(session.sessionId)` → 再呼叫一次 `_start()` → `_apply`。409 `SESSION_ALREADY_COMPLETED` 經新的回呼（例如 `onAbandonNotice(String message)`）交回畫面顯示 SnackBar，然後照樣重新 start；其他錯誤走既有 `_fail`。
    - 重新 start 若又回 `conflictingLevel`（極少見，例如另一台裝置剛開了新測驗），再走一次對話框，不要直接續接。
  - `lesson_card_screen.dart`：`confirmConflict` 改用 `showDialog` + `AppDialog`，主要按鈕「繼續「old」測驗」，次要按鈕「放棄並開始「wanted」」「返回」；文字長度要在窄螢幕排得下，次要按鈕放不下時改成主要按鈕下方直排，視實機決定。選放棄時在回呼內先跳 `showConfirmDialog` 二次確認，取消就重新顯示三選項對話框，確認才回傳 `abandon`。
  - `quiz_flow_controller_test.dart` 補：選 abandon 會依序呼叫 abandon 與第二次 start、404 被吞、409 會呼叫通知回呼後仍開出新測驗、abandon 失敗進 error、重新 start 又衝突時再問一次；既有「衝突時拒絕續接」測試改成新列舉。

**依賴**：無

**風險 / 待決**：首頁或學習頁是否有「未完成測驗」提示要依賴 `LearnRefreshNotifier` 刷新，動手時確認放棄後要不要通知；沒有此提示就刪掉對應驗收條件。

**進度**：實作完成（2026-10-01）
- commit：06a864f、d47009a、02b41b4、50ff69e、53adab5
- 決定：放棄後呼叫 `LearnRefreshNotifier.bump()`，等級頁的「進行中」標籤與測驗紀錄跟著重抓；三選一對話框的次要按鈕改直排（`AppDialog.stackSecondary`），避免「放棄舊測驗，開始「中高級」」在 360 寬擠成兩行；404 只在 service 吞掉，controller 不重複處理
- 未驗：inspector 的 `POST /api/quiz/abandon` 尚未在裝置上跑（需人點 Google 帳號）；實機走一次放棄流程並確認回學習頁後「初級」不再顯示進行中
