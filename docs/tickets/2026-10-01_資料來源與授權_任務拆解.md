## 現況與前提

- 技術棧：Flutter（Android／iOS 為主），HTTP 走 `ApiClient`，錯誤統一成 `ApiException`；service 測試用 `ApiClient.httpClient` 換 `MockClient`（`installMockClient`，見 `test/services/event_service_images_test.dart`）。
- 既有相關機制：
  - `AboutAppScreen`（`lib/screens/profile/about_app_screen.dart`）是 `StatelessWidget`，檔頭寫「純靜態內容，不打 API」。入口有兩個：首頁頂端 logo（`home_screen.dart`）與個人資料「其他」→「關於」（`profile_screen.dart`）。
  - 「資料來源與授權」區塊已預留（#101）：`_showDataSources = false`、`_dataSources` 是一筆佔位文字、`_buildDataSources` 畫成米色圓角卡，名稱用 `AppTypography.titleStyle`、內文用 `bodyStyle`，有長輩模式字級。測試用的 `debugShowDataSources` 參數可強制打開。
  - `test/widgets/about_app_data_sources_test.dart` 測「開關關閉時不出現」與「打開時 320dp 寬不 overflow（一般／長輩模式）」。
  - 外部連結慣例：`launchUrl(uri, mode: LaunchMode.externalApplication)`（`video_detail_screen.dart`、`app_update_prompt.dart`）。
  - API 契約：`integration_test/api_inspector_test.dart` 錄 raw 回應與 fixture（`test/fixtures/api/`），`test/contract/api_contract_test.dart` 把 fixture 餵進 model 的 `fromJson`。
- 這次會動到的既有部位：`lib/core/constants/api.dart`、`lib/screens/profile/about_app_screen.dart`、`test/widgets/about_app_data_sources_test.dart`、`integration_test/api_inspector_test.dart`、`test/contract/api_contract_test.dart`；新增 model 與 service 各一檔。
- 分支狀態：目前在 `feat/event-images`（A2，尚有未 commit 的改動）。A3 從 `origin/master` 另開分支。`pubspec.yaml` 目前 `1.0.0+16`。
- 已定案的技術前提：
  - `GET /api/data-sources` 不需登入，回 `{ title, sources: [{ id, name, used_for, license, attribution, links: [{ label, url }] }] }`；2026-10-02 用 curl 打正式環境，回應與文件一致，目前三筆（klokah、curriculum、youtube），youtube 的 `license` 為 `null`、`links` 為 `[]`。
  - 筆數與順序以回應為準，照陣列依序顯示；`id` 穩定可當 key。
  - `attribution` 原樣顯示，不截斷、不改寫。
  - 讀取失敗顯示「暫時無法載入資料來源，請稍後再試」，不退回寫死的文字；App 內不留任何寫死的來源文字。
  - 回應帶 `Cache-Control: private, max-age=3600`；`http` 套件不做快取，每次進頁都重打，量很小不另做快取。
  - 學習內容不逐題標示、文章與影片維持各自的出處（決策 A42），App 其他地方不用改。
  - 每筆 `name` 下方顯示 `used_for` 小標籤，`license` 不另外顯示。
  - 讀取失敗只顯示文字，不加重試按鈕。
  - 活動圖片（A2）不升版，A3 升 `1.0.0+17`。

## 任務卡

### T-01 使用者在「關於」頁看到資料來源與授權，能點開出處與授權條款

**使用者價值**：使用者（與授權方）能在 App 內看到族語教材的出處與 CC 授權標示，符合授權條款要求；之後改文字或新增來源，後端部署就生效，不用等 App 更新。

**範圍**
- 包含：`GET /api/data-sources` 的 inspector 測試與 fixture、model、service、「關於」頁區塊改接 API（含讀取中、失敗）、拿掉 `_showDataSources`、`_dataSources`、`debugShowDataSources`。
- 不包含：升版（T-02）。

**驗收條件**
- [ ] 進「關於」頁，上半部品牌內容立即顯示；捲到底看到「資料來源與授權」，下面依序是原住民族語E樂園、十二年國教教材、影音（YouTube 影片）三段
- [ ] 每段的小標題是 `name`，下方是 `used_for` 小標籤，內文是完整的 `attribution`，跟 API 回應逐字相同、沒有省略號
- [ ] 每段的 `links` 顯示成可點的文字連結，點了用外部瀏覽器開啟對應網址；YouTube 那段沒有連結，也不留空白
- [ ] 讀取中，區塊位置顯示載入指示，不跳版
- [ ] 斷網進頁：區塊顯示「暫時無法載入資料來源，請稍後再試」，不出現任何寫死的來源文字
- [ ] 320dp 寬、一般與長輩模式都不 overflow，長輩模式字級放大

**實作設計**
- 前端：
  - 先在 `api_inspector_test.dart` 加 `GET /api/data-sources` raw 測試並錄 `get_api_data_sources.json`；回應沒有個資，不用補遮罩。跟下一批需要點 Google 帳號的錄製一起跑。
  - `ApiConfig` 加 `dataSources = '/api/data-sources'`。
  - 新增 `lib/models/data_source_models.dart`：`DataSources { title, sources }`、`DataSource { id, name, usedFor, license?, attribution, links }`、`DataSourceLink { label, url }`；`links`、`used_for` 缺欄位時當空陣列。`api_contract_test.dart` 加一筆 `_Contract`。
  - 新增 `lib/services/data_source_service.dart`：`DataSourceService.fetch()` → `ApiClient.get(ApiConfig.dataSources)` → `DataSources.fromJson`。`ApiClient.get` 有 token 就帶，後端不受影響，不用另開不帶 token 的路徑。
  - `about_app_screen.dart`：
    - 外層維持 `StatelessWidget`，區塊抽成私有的 `_DataSourcesSection`（`StatefulWidget`），`initState` 呼叫一次 `fetch()` 存成 `Future`，用 `FutureBuilder` 畫三種狀態；只有這塊重畫，品牌內容不受影響。
    - 區塊標題 `_sectionLabel` 一律顯示：成功時用 API 的 `title`，讀取中與失敗時用「資料來源與授權」。
    - 成功：沿用 `_buildDataSources` 的米色卡，每筆 `name`（titleStyle）→ `used_for` 小標籤（`Wrap`，空陣列不顯示）→ `attribution`（bodyStyle，`SelectableText` 方便引用）→ `links` 用 `Wrap` 排成帶外連 icon 的文字按鈕，`launchUrl(..., mode: LaunchMode.externalApplication)`，開不了時 SnackBar「無法開啟連結」。
    - 失敗：同一張卡內只顯示錯誤文字。
    - 更新檔頭註解，拿掉「純靜態內容，不打 API」。
  - 測試：`about_app_data_sources_test.dart` 改用 `installMockClient`：成功時三段 `name` 與完整 `attribution` 都找得到、空 `links` 不出現連結；回 500 時顯示失敗文案且找不到 fixture 裡的任何 `name`；320dp 一般／長輩模式不 overflow。刪掉「開關預設關閉」那支。

**依賴**：無

**風險 / 待決**：`attribution` 很長，長輩模式下卡片會很高，實機確認閱讀起來不吃力；`launchUrl` 在 Android 11+ 需要 `<queries>` 宣告 https intent，既有影片連結已能開就代表已宣告，動手時順手確認。

**進度**：未完成
